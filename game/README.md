#GameVault

Современная веб-платформа и каталог видеоигр на чистом стеке **HTML5 / Tailwind CSS / Vanilla JS** (без тяжелых фреймворков и этапа сборки). Включает базу из 10 000+ игр, синхронизацию с облаком через Google Firebase, интерактивную ленту новостей игровой индустрии и социальную систему публичных профилей.

---

##Ключевые возможности

-  **Каталог 10 000+ игр**: фильтрация по жанрам, платформам, годам, поиск на лету, пагинация и сортировки по популярности/рейтингу.
-  **Глубокая аналитика и оценки**: 10-балльная шкала, интерактивная диаграмма распределения голосов, интеграция рейтингов Steam, PlayGround и Metacritic.
-  **Личные списки**: категории *«Хочу пройти»*, *«Прошёл»*, *«Бросил»* с сохранением в локальное хранилище и облачный профиль.
-  **Лента новостей индустрии**: адаптивный ридер статей, система тегов, счетчики прочтений, лайки, интерактивные цитаты разработчиков и карточки связанных игр.
-  **Публичные профили и сообщество**: страницы пользователей с их персональным оформлением, оценками, любимыми играми, а также система взаимных подписок на Firestore.
-  **Гибридная авторизация (Firebase Auth)**: вход через Google, Email/пароль или беспарольный вход по ссылке на почту (Passwordless).
-  **Звуковой движок (Web Audio)**: звуки интерфейса, переходов и ачивок (с возможностью отключения).
-  **Полный адаптив**: оптимизированный интерфейс для смартфонов, планшетов и широкоформатных мониторов с плавной темой Dark Glassmorphism.

##Структура проекта

```text
game/
├── index.html                  # Главная разметка, модальные окна, шапка, подвал, подключение скриптов
├── firestore.rules             # Правила безопасности для базы данных Firestore
├── css/
│   └── styles.css              # Пользовательские стили, анимации, скроллбар и эффекты стекла
├── assets/                     # Статические ресурсы (иконки, изображения)
├── js/
│   ├── config.js               # Конфигурация Firebase
│   ├── tailwind-config.js      # Кастомные шрифты и цветовая палитра Tailwind
│   ├── state.js                # Глобальное реактивное состояние приложения
│   ├── router.js               # Маршрутизатор представлений showView() с поддержкой параметров
│   ├── games.js                # Каталог ~10 000 игр (метаданные, постеры, скриншоты, оценки)
│   ├── descriptions.js         # База описаний и разработчиков на русском языке
│   ├── details.js              # Связывание данных каталога с расширенными описаниями
│   ├── news-data.js            # База статей игровой ленты и обработка реакций
│   ├── rating-stats.js         # Математика и распределение пользовательских оценок
│   ├── demo-reviews.js         # Генератор демо-рецензий для наполнения страниц
│   ├── reviews.js              # Модальное окно написания рецензий и их отправка
│   ├── public-profiles.js      # Система профилей сообщества, подписок и синхронизации с Firestore
│   ├── audio.js                # Аудио-эффекты интерфейса на базе Web Audio API
│   ├── actions.js              # Управление списками, выставление оценок, шэринг, лайтбокс скриншотов
│   ├── auth/
│   │   ├── auth-ui.js          # Модальные окна авторизации/регистрации, валидация и уведомления
│   │   └── firebase.js         # Клиентская обёртка Firebase Auth и базы Firestore (window.GVAuth)
│   └── views/
│       ├── components.js       # Универсальные UI-компоненты (карточки игр, бейджи, проверка релизов)
│       ├── home.js             # Главная страница: хиты, новинки, жанровые подборки, свежие новости
│       ├── catalog.js          # Каталог с фильтрами, поиском в реальном времени и тегами
│       ├── game.js             # Детальная страница игры: постеры, оценки, вердикты, рецензии
│       ├── news.js             # Лента игровых новостей и полноэкранный ридер статей
│       ├── tops.js             # Топы лучших игр по годам и платформам
│       └── profile.js          # Личный кабинет и просмотр чужих профилей
└── tools/                      # Утилиты автоматического сбора данных и переводов
    ├── enrich_missing.py       # Обогащение описаний (Википедия + Steam + RAWG)
    ├── scrape_descriptions.py  # Скрапер описаний и разработчиков
    └── fetch_descriptions.py   # Выгрузка описаний через официальный API RAWG
```
